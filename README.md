# SuCRIT dashboard draft

Draft dashboard for the SuCRIT clean-power indicators (v5, 3 Nov 2026). It has three tabs: Story, Report card and Operations. Built for discussion; 2026 values are estimates, and some indicators use proxy, modelled or mock values.

Live: https://akansha030.github.io/sucrit-dashboard/

Options to compare (for the 4 Nov stakeholder call): https://akansha030.github.io/sucrit-dashboard/options.html shows the same dashboard as Minimal, Balanced, Dense, Narrative, State-first and What changed, plus a Decide view. Add `?opt=a` … `?opt=f` or `?opt=decide` to open one directly.
